## Project Overview

TPRM is embedded C firmware for an **ATxmega128A1**-based Environmental Monitoring System (EMS). It monitors differential pressure (DP1/DP2/DP3), temperature, humidity, and particulate matter, and drives alarms, analog 4–20mA outputs, PID control loops, and RS485 serial communication.

## Build System

The **active build system is Atmel Studio 7 / Microchip Studio** using `TPRM_6_2(1).cproj`. Open this project file in Atmel Studio to build, debug, and flash.

- Build output directory: `default/`
- Output artifacts: `TPRM.elf`, `TPRM.hex`, `TPRM.eep`, `TPRM.lss`
- Programmer: **Atmel-ICE** via **PDI** interface at 4 MHz

The legacy `Makefile` in the root targets `atmega32` and is **outdated** — do not use it.

The `default/Makefile` is auto-generated by Atmel Studio and includes all source files in the build.

**Compiler flags (from the generated makefile):**
```
-mmcu=atxmega128a1 -Wall -O2 -std=gnu99 -funsigned-char -funsigned-bitfields -fpack-struct -fshort-enums
```

## Architecture

### Bare-Metal Super-Loop (no RTOS)

Despite FreeRTOS source being present in `FreeRTOS/`, the current firmware runs a **bare-metal super-loop**. `vTaskStartScheduler()` is commented out in `TPRM.c`. The OS abstraction layer (`os_api.h`) allows switching between FreeRTOS and AvrX by defining `OS_AVRX` or leaving it undefined (defaults to FreeRTOS wrappers used for EEPROM and semaphore primitives only).

The main loop is paced by an **internal RTC overflow ISR** (`RTC_OVF_vect`) firing every **50ms** (32kHz RC oscillator, DIV1 prescaler, PER=50 → ~50ms). Task timing:

| Task | Period | Function |
|------|--------|----------|
| Serial I/O | Every loop iteration | `SerialInterfaceTask()` |
| User Interface / Display | 50 ms | `UserInterfaceTask()` |
| Pressure sensor read | 250 ms | `DEVICEIO_FUNC_NAME()` |
| Temp/RH sensor read | 250 ms | `TEMPRHIO_FUNC_NAME()` |
| Periodic (logging, broadcast) | 1 second | `PERIODIC_FUNC_NAME()` |

### Module Responsibilities

| File | Responsibility |
|------|---------------|
| `TPRM.c` | Entry point, clock/GPIO init, reset reason detection, super-loop |
| `UserInterface.c` | GLCD display, keypad input, parameter menu navigation, alarm display |
| `DeviceIO.c` | Sensor acquisition, alarm logic, 4–20mA analog output scaling |
| `SerialInterface.c` | RS485 Modbus-like protocol (USARTC0/C1), broadcast, printer output |
| `PID.c` | PID controllers for DP1, DP2, Temp, RH channels |
| `PeriodicProcess.c` | 1-second tasks: EEPROM logging, serial broadcast, RTC sync |
| `HardwareInfo.c` | Feature capability queries (reads `CONFIG_SYSTEM` bitmask from EEPROM) |
| `os_api.c/.h` | OS abstraction: EEPROM read/write wrappers, semaphore macros |
| `eepromAdr.h` | All EEPROM address definitions (`EA_*` constants, word-aligned at `N*2`) |
| `error.h` | Error code constants (`ERROR_*`) |

### I2C Bus Assignments (Software I2C via `SWTWImaster/`)

| Bus | Port Pins | Connected Peripherals |
|-----|-----------|----------------------|
| SW_I2C1 | PC0 (SDA), PC1 (SCL) | DAC7573 (analog out), GLCD |
| SW_I2C2 | PD0 (SDA), PD1 (SCL) | DP1 pressure sensor, Temp/RH sensor, RTC |
| SW_I2C3 | PE0 (SDA), PE1 (SCL) | DP3 pressure sensor, post-temp sensor |
| SW_I2C4 | PF0 (SDA), PF1 (SCL) | DP2 pressure sensor, particulate sensor |

### Parameter System

All user-configurable settings are persisted in **on-chip EEPROM** as 16-bit words (word-aligned). The `PARAMETER` enum in `UserInterface.h` defines ~192 parameter IDs. Access via:

```c
GetParameter(paraId, &value);   // read
SetParameter(paraId, &value);   // write (validates range)
GetParameterStr(paraId, buf);   // for string parameters
```

EEPROM addresses are defined in `eepromAdr.h` as `EA_<PARAM_NAME>` macros using `(N*2)` byte addressing.

The `CONFIG_SYSTEM` EEPROM word is a bitmask controlling enabled features. `HardwareInfo.c` provides `Is*Enabled()` query functions that read this bitmask — always use these rather than reading EEPROM directly to check feature state.

First-run defaults are written when `EA_DEFAULT_SAVE != 0xABCD` (written once to mark EEPROM as initialized).

### Sensor Support

- **Pressure**: SM9543 or XGZP6891D (selectable via `PRES_SENS_TYPE` parameter)
- **Temp/RH**: SHT25 or IDT HS3100 (selectable via `TEMP_RH_SENS_TYPE` parameter)
- **Particulate**: SEN55 or IPS7100/ISP5100 (selectable via `PARTICAL_SENS_TYPE` parameter)
- **DAC output**: DAC7573 (I2C, 4 channels, 12-bit) for 4–20mA outputs

### RS485 Serial Protocol

Two RS485 ports on USARTC0 and USARTC1. Direction control via PC4 (DE1) and PC5 (DE2). The protocol supports Modbus-like framing with CRC (`CalCRC()`). Baud rate and framing are configurable via EEPROM parameters (`SERIAL_BAUD_RATE_VAL`, `SERIAL_DATA_STOP_PARITY_VAL`).

## Release Artifacts

Built `.hex`/`.eep`/`.elf` files for each release are kept in `default/` with version-stamped names (e.g., `TPRM_V2_9_7_BareMetal_NewFont.hex`). When releasing a new version, copy the build outputs and rename with the version tag before committing.
